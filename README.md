# まごころ弁当 業務管理アプリ

まごころ弁当の管理者・スタッフ向けの、スマホ用の業務アプリです。主な機能は **トーク** と **シフト確認** で、配達報告・要対応・打刻は引き続き使えます。
画面の流れはLINEに近づけています（配色・アイコンはオリジナル）。

## できること

- **トーク** — 全体グループと1対1。新しい順の一覧（最新メッセージ・時刻・未読数）、左右の吹き出し、日付の区切り、「既読」（グループは「既読3」）、写真・ファイル送信、画面下に固定の入力欄
- **シフト確認** — 確定シフトを「自分／日ごと／人ごと」で表示（期間は21日〜翌20日）。自分の次の出勤日を最上部に表示。日ごとは業務（配達4・厨房1・管理）の区画に分け、不足人数が分かる。研修日は配達5人
- **管理者のシフト登録** — 日ごとの画面で日をタップして、担当者・業務・区分（終日／午前／午後）を手入力
- **メンバー管理（管理者）** — スタッフの追加・削除（勤怠タブ → メンバー管理）
- **報告・要対応・打刻・シフト希望提出** — 従来の機能（報告タブ、要対応タブ（管理者のみ）、勤怠タブ、シフト → 希望提出）

## 仮仕様（店長に確認するまで）

コード内に `仮仕様:` のコメントがあります。
- 確定シフトは管理者が手入力（既存シフトアプリからの取り込みは未対応）
- ログインは名前＋暗証番号のまま（Firebase Authなし）
- 写真・ファイルはFirestoreに保存（ファイルは600KBまで）
- 通知はアプリを開いている間だけ（PWAプッシュ通知は未対応）
- 退職者を削除しても、過去のメッセージ・報告は残す
- 希望提出はこのアプリにも残してある

## 動かし方

`index.html` を静的サーバーで開くだけです（ビルド不要）。`config.js` に Firebase 設定があれば本番版、無ければデモ体験版で動きます。
URLに `?demo` を付けると、設定があってもデモ体験版で開けます（店長への見せ用・動作確認用）。
デモの暗証番号はすべて `1234`（管理者は「原田」、スタッフは「Homa」「細川」など）。

最初の管理者は、ログイン画面の「新規登録」から管理者コード（`config.js` の `ADMIN_CODE`）で登録します。以降のスタッフは管理者が追加します。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | デザイン（藍・梅・卵の配色、お弁当箱の仕切りがモチーフ） |
| `app.js` | アプリのロジックとデータ層（デモ／Firebase） |
| `config.js` | Firebase設定・管理者コード |
| `セットアップ手順.md` | Firebase再利用＋GitHub公開の手順 |

## Firestore のコレクション

`reports` `comments` `announcements` `shifts`（希望）`timecards` `images` `accounts` `messages`（`readBy` を追加）、新規 `confirmedShifts`（確定シフト）と `shiftDays`（研修日）。
