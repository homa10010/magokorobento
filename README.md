# 🍱 まごころ配達ノート

まごころ弁当の配達バイト向けの、配達報告・要対応・シフト管理アプリです。
スマホのブラウザで動く1ファイル(`index.html`)のアプリで、LINEでバラバラに送っていた報告を、
ルート別・種類別に整理して共有できます。

## できること

- **定型フォーム報告** — 不在・保冷箱／キャンセル・中止／変更・依頼／集金／試食・新規／配達完了／その他・トラブル を、ボタンとフォームで報告(自由文と違って必要な項目が必ず揃います)
- **ルート別・種類別の絞り込み** — ルート1〜4・厨房、種類ごとにタイムラインを表示
- **要対応リスト** — 配達完了以外の報告は自動でリスト化。管理者がエクセルに反映したら「済」で消し込み(誰がいつ処理したか記録)→ 転記漏れを防止
- **シフト提出** — 「21日〜翌月20日」の期間ごとに、出勤できる日を複数選択して一括提出(締切は毎月8日)。誰が出勤できるかは管理者だけが閲覧
- **写真添付** — 表札や車両などの写真を1枚添付(自動で軽く圧縮)
- **送信取り消し** — 自分の報告を取り消し可能(管理者は全員分)
- **アカウント制** — 名前＋暗証番号で登録・ログイン。管理者は管理者コードが必要

## 使い方

1. スマホのブラウザで公開URLを開く
2. 「新規登録」で名前と暗証番号(4〜8桁の数字)を登録
3. 下のメニューから「報告する」「要対応」「シフト」を使う

そのまま開くと **デモ体験版**(データは端末内のみ)として動きます。
全員でリアルタイム共有する **本番版** にするには、[セットアップ手順.md](./セットアップ手順.md) の通りに
Firebase(無料)の設定を `index.html` に貼り付けてください。

## 公開(ホスティング)について

このリポジトリを GitHub Pages で公開すると、`index.html` がそのままアプリのURLになります。
コードを更新してアップロードし直すたびに、公開中のアプリも自動で切り替わります。
設定方法は [GitHubガイド.md](./GitHubガイド.md) を参照してください。
