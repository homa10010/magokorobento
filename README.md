# 🍱 まごころ配達ノート

まごころ弁当の配達バイト向けの、配達報告・要対応・シフト・打刻をまとめたスマホ用アプリです。
LINEでバラバラに送っていた報告を、ルート別・種類別に整理して共有できます。`index.html` 1ファイルで動きます。

## できること

- **定型フォーム報告** — 不在・保冷箱／キャンセル／変更／集金／試食／配達完了／その他・トラブル を、ボタンとフォームで報告(必要な項目が必ず揃う)
- **タイムライン検索** — ルート別・種類別の絞り込みに加え、キーワード・報告した人・日付でも検索
- **要対応リスト** — 配達完了以外は自動でリスト化。管理者が「済」で消し込み(誰がいつ処理したか記録)
- **シフト提出** — 21日〜翌月20日の期間ごとに出勤できる日を複数選んで提出。管理者は1日単位の一覧で確認
- **タイムカード(打刻)** — 出勤・退勤を押すだけ。期間の合計勤務時間を自動計算。管理者は全員分を閲覧
- **写真添付／送信取り消し／アカウント制(名前＋暗証番号)**
